# 静默回声

默认入口现为格雷文港单人剧情战役：十六章、四十个分区，沿用俯视自动射击，加入独行探索、军医同行、四人小队、空袭标定、现场档案和检查点。经典演练保留在独立入口，旧成绩与外观记录不迁移、不覆盖。

历史验收资源包使用 Git LFS 管理。需要完整克隆所有资源时，请先安装 Git LFS 并运行 `git lfs install`；运行游戏使用仓库中的源码和 `public` 资源。

```sh
npm install
npm run dev
```

本机入口为 http://127.0.0.1:5186/ 。经典演练使用 `?mode=classic`。只需桌面浏览器，无账户、远程游戏服务或在线模型调用。

- WASD / 方向键：移动；枪械自动索敌射击。
- F：操作设备、救援倒地队友、收集现场记录、进入下一分区。
- R：换弹；空格：手雷；C：暂停式空袭标定，第六章解锁。
- Q：小队跟随 / 原地留守；J：现场档案和无线电记录。
- Esc：暂停；滚轮：缩放。

在主菜单配置三种武器、配件和角色外观。行动中不允许通过换枪补满弹药。新战役与继续战役各有明确入口；章节重玩不覆盖主线检查点。

检查点记录任务、敌人、补给、小队、空袭与资源状态，保留上一份有效记录。存储不可用时仍可在本次会话内重试，但刷新页面不能恢复未写入的数据。

剧情约三小时为设计目标，尚需真人完整游玩校准。当前九个固定自动路线样本用时约七十二至九十五分钟，不能据此宣称三小时目标已经达成。画面采用现有模型与代码生成的模块化场景；当前不含人物配音、联机或移动端适配。

```sh
npm test
npm run build
npm run test:campaign
npm run test:story
npm run test:story:matrix
```

剧情路线、实现结构和验收边界见 [战役说明](docs/design/silent-echo-campaign.md)。本轮未使用付费生成服务，也未修改原始模型资产。

## 经典演练与既有资产记录

本地浏览器三维自动射击游戏。当前包含一张三分钟训练地图、三张后续战役地图、可换装士兵、三种枪械，以及城市、车辆和敌人资产。后续关卡以任务、首领和撤离组成完整流程，最早撤离时间分别为四、五、六分钟。

## 运行

需要 Node.js 22.12 或更高版本。

```sh
npm install
npm run dev
```

固定地址为 http://127.0.0.1:5186/ ，本机 Chrome 和内置浏览器均使用此地址。开发端口固定为 5186，已占用时直接报错，不自动切换；生产预览端口为 5187。方向键或 WASD 移动，自动索敌、射击、换弹和拾取；R 提前换弹。ESC 暂停，滚轮缩放。切换窗口自动暂停。训练关巨兽在两分钟出现，击败并撑到三分钟后结束。战役关需按简报完成目标、击败首领并进入撤离区；计时归零后可以继续补做任务，补给持续投放。

```sh
npm test
npm run build
npm run test:campaign
```

## 后续战役

| 关卡 | 最早撤离 | 核心任务 | 首领条件 |

| 断线重连 | 四分钟 | 修复两座终端，各累计十二秒，圈内敌人打断操作 | 两分三十秒 |
| 灰烬补给线 | 五分钟 | 回收三处物资，各停留三秒，补充弹药、医疗与手雷 | 三分三十秒 |

首次打开直接选择「断线重连」，训练关随时可重玩；通关解锁下一关，重新打开默认选择已解锁且尚未完成的战役关。选关保留枪械和配件，生命、弹药、手雷和局内强化每关重新初始化。解锁保存在当前浏览器；存储失败时仍保留本次会话的解锁。

场景光圈、任务进度、方向距离和战术地图同步显示目标。详细布局、节奏和验收见 [后续关卡设计](docs/design/campaign-levels.md) 与 [战役验收及审查](docs/development/campaign-review.md)。

## 已接入内容

- 士兵真实骨骼行走动画、独立上半身朝向、自动步枪及程序握点。
- 四座真实商店废墟、四块道路掩体；实际模型尺寸与移动、弹道、视线阻挡共用配置，遮挡角色时透明化。
- 轿车、装甲车、警车三辆真实残骸，以及独立动态火焰、烟雾和火光。
- 人类突击兵、人类步枪兵、外星扑击兽、外星喷射者、裂城巨兽五类真实敌人；分别实现近战、蓄力射击、预警冲刺、三发散射和范围攻击。
- 敌人按体型寻路与刷怪，五类模型合批绘制，敌方武器取自已生成的同一把步枪。
- 连续弹道碰撞、自动换弹、生命和护甲、经验拾取、暂停三选一强化、胜负结算、重试。
- 有限弹药：二十四发弹匣、开局一百二十发备弹、备弹上限二百四十发；换弹一点七秒，带弹匣与手部动作及机械音效。普通敌人四成概率掉十二发，首领必掉四十八发；补给箱每箱七十二发，靠近自动打开，装不下的保留。缺弹显示附近补给箱的方向与距离。
- 枪口火焰、烟气、后坐力、抛壳与瞬时光照；高速短曳光、墙面火星和身体命中尘屑。
- IndexedDB 按关卡保存行动成绩；本机存储记录战役解锁，不包含永久升级经济或跨设备同步。

## 资产与验收边界

原始模型与 Blender 母版保留在 assets。游戏副本位于 public/models/game；静态模型减到七千至两万面，使用一千像素贴图。敌方步枪另行合并为两千八百面顶点色副本，玩家步枪保留原材质。导出脚本为 scripts/prepare-game-models.py，需在独立 Blender 后台进程运行。

新增五类敌人使用程序步态、呼吸、蓄力与瞄准姿势，尚不属于最终骨骼和手部动画。八至十二分钟长关卡、自动火箭副武器、局外装备、永久升级与资源经济仍待实现。三十分钟稳定性和真人正常难度平衡仍待验收。当前七十四项自动测试与三关九种标准武器组合的完整固定样本通过，具体边界见战役验收记录。

当前四十二项自动检查通过，包含真实行走片段、双手握点、蒙皮同步移动、枪口对齐、高速弹道回归、有限弹药守恒、换弹和补给生命周期。弹药设计、固定整局与浏览器验收见 [弹药与补给](docs/development/ammunition.md)。模型接入阶段曾在 M5 Pro、48GB、本机 Chrome 的六十真实敌人场景验证，1920×1080 渲染缓冲，预热后约六十六秒平均约一百二十帧，百分之九十五帧间隔约十点二毫秒。该历史样本的可见浏览器视口为 1075×656；压力模式使用额外生命与零玩家伤害保持六十敌人，不作为正常难度证据。开火特效本轮验证另见 [开火与弹道优化](docs/development/gunfire-effects.md)。

详细结果见 [模型接入记录](docs/development/model-integration.md)、[浏览器数据](docs/development/model-integration-browser.json)。静态制作历史见 [建模交付记录](docs/modeling/environment-enemy-progress.md) 和 [警车记录](docs/modeling/burned-police-car-progress.md)。项目累计使用六百一十积分，二千积分预算内剩余一千三百九十积分；本轮接入未消耗新 Tripo 积分。

移动时人枪分离的复现、根因和修复验证见 [持枪修复记录](docs/development/actor-attachment-fix.md)。

界面现已改为全屏战术 HUD：生命、经验、弹药、击倒和阶段使用图形与紧凑读数；巨兽拥有独立血条。H 打开帮助，数字键 1、2、3 可选择强化。图像设计、提示词及实机验收见 [界面设计](docs/design/hud-design.md) 和 [界面审查](docs/development/hud-review.md)。

## 枪械配件与主动手雷

开局点击“装备配置”，选择手枪、冲锋枪或突击步枪，并安装兼容的瞄具、扩容弹匣、加固枪托和前握把。手枪不支持前握把。三维预览与属性同步更新，进入战斗后配置锁定；暂停或结算后可点“更换装备”开始新行动。

基础射速按手枪、冲锋枪、突击步枪递增，分别为每分钟一百、三百、五百发；这是连续开火速率，不包含换弹时间。配件与局内强化后的射速上限分别为每分钟一百五十、四百、七百五十发，低阶武器强化后仍慢于下一档标准武器。达到上限后禁用射速强化，保留本次机会供其他强化使用。调整与验收见 [武器射速分档](docs/development/weapon-cadence.md)。

瞄具减少百分之四十五散布，扩容弹匣增加百分之五十容量，加固枪托提升百分之十五射速，前握把减少百分之二十散布并增加百分之八射速。每局三枚手雷，按空格或点击手雷按钮主动投掷；长按不连投，冷却零点六五秒。投掷自动朝当前目标，无目标时沿角色朝向；近处目标采用短投，爆炸伤害受掩体遮挡。

手枪、冲锋枪现已改为按原图通过 Tripo 生成的细节模型；原始文件保留四千像素颜色、物理材质与法线贴图，游戏副本使用二千像素贴图并保留完整表面网格。突击步枪沿用已有 Tripo 模型，手雷与冲锋枪前握把仍复用原免费素材。火箭炮原图模型已生成并保存母版，尚未新增对应玩法。来源与实际采用情况见 [来源记录](docs/modeling/weapon-asset-sources.json)，最新交付见 [原图武器接入](docs/development/weapon-tripo-delivery-v2.md)。长期正常难度平衡及百分之八十人工节省仍未验证。

## 素装士兵与角色换装

主菜单点击“角色换装”或按 E，可在素装、轻装、中装、全副武装和原主角间切换。当前十五类穿戴位置对应原图的头部、胸背、肩颈、肘前臂、腰侧、大腿、膝小腿与手脚。三档防弹衣互斥；十四类其他部件可独立开关。支持正背切换、装备展示、行走、持枪及换弹预览。选择立即应用到战斗角色并保存；战斗中打开暂停，关闭后继续。首次使用默认素装。

完整造型来自原始可编辑母版，并适配到已通过方向检查的新素装人物。当前游戏副本为 public/models/game/modular-soldier-v5.glb，可编辑母版为 assets/models/masters/modular-soldier-headgear-v5.blend。第五版保留第四版脸型与人体，修正头盔、目镜、耳机及下颌带；六十四项检查与同机位近景见 [头部装备验收](docs/development/headgear-v5-validation.md)。原角色、第三版、第四版和十件原始独立装备保留；上一版接入记录见 [完整武装验收](docs/development/full-kit-v4-validation.md)。

当前为外观换装；装备掉落、收集解锁和属性成长仍待实现。织物磨损细节和独立手指抓握尚未完成最终精修。本轮无新增 Tripo 消耗，项目累计一千一百九十积分，预算内余八百一十积分，以 [项目账本](assets/models/tripo/tasks.json) 为准。
