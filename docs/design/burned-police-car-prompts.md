# 燃烧警车设计与建模提示词

生成方式：内置 ImageGen。用户明确要求新增一辆着火警车并交给 Tripo 建模，本轮按该授权完成设计与静态建模。

## 设计图提示词

用途：写实军事科幻网页游戏《破城前线》的车辆设计图。新增一辆可识别的黑白配色四门警用轿车残骸，车顶保留蓝红双段警灯，侧门保留原创简化盾形警徽图案，不采用真实品牌或真实警队标志，不需要任何文字。车辆前部撞损，发动机盖局部翘起，挡风玻璃破裂，黑白车漆焦黑剥落，四轮与完整底盘可辨认。左侧主图显示发动机舱正在燃烧的橙色火焰和适量深灰烟雾，火焰不遮挡车辆轮廓；右侧展示同一辆警车的正面、背面、左侧、右侧四个严格等比例正交视图，四视图没有火焰和烟雾，清楚展示同样的车身损伤、警灯和材质。统一写实物理材质三维游戏美术，与已有破碎轿车、装甲车的风格一致。浅灰摄影棚背景，完整车辆不裁切，无人物、其他车辆、环境街景或水印，无文字。所有视角必须是同一个物体，不允许视角之间改变车型、车灯、车门或轮毂设计。

## 独立建模参考图提示词

以设计图作为外观与车体身份参考。仅输出其中同一辆警车残骸的单个前侧三分之四视角，完整车辆居中，浅灰摄影棚背景。移除所有火焰、烟雾、漂浮火星及火焰造成的橙色光照；保留黑白车漆、蓝红车顶警灯、焦黑战损、破裂玻璃、四个轮子与完整底盘，不改变车型和损伤。不要设计板、拼图、文字、水印、人物或地面场景。该图将作为 Tripo 单体建模输入，火焰烟雾将在游戏阶段单独制作动态特效。
