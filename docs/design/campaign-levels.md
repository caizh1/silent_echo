# 后续关卡设计

## 目标与边界

原有人工体验基线是一张三分钟废城生存地图：移动、自动射击、拾取、升级、击败巨兽。所有新地图继续使用现有模型和操作方式，目标用户是已经能完成基本走位与换弹的键盘玩家。新增目标要求玩家选择路线、抢修时机和补给顺序。

本次交付三张可以实际进入、完成、结算并解锁下一张的地图。保留训练地图，不把旧版玩家挡在必须重新通关的门槛后。四、五、六分钟是最早撤离时间，战斗及赶路会增加实际用时。完整八至十二分钟长关卡、移动触屏操作、永久成长和联机不在本次范围内。

输入使用已有城市废墟、道路掩体、燃烧车辆、五类敌人和三种武器。关卡不依赖模型服务或新下载。任务点以地面光圈和投影表达交互范围；战术地图与场景使用相同坐标。不同地图使用独立碰撞数据，地形同时约束移动、索敌、子弹、手雷、补给和敌人寻路。

## 第二关：断线重连

冷蓝色通信街区，南侧进入，同侧撤离。两座终端分布在道路两侧，中央错位掩体和两辆残骸形成转场路线，不能站在同一位置同时完成任务。

| 时段 | 压力与目标 |
| --- | --- |
| 开局至一分十五秒 | 突击兵与步枪兵，常规生成间隔二点四秒；选择先修哪座终端 |
| 一分十五秒至两分三十秒 | 加入扑击兽，间隔一点九秒；通过预警学习离圈再返回 |
| 两分三十秒之后 | 巨兽出现，常规间隔回落至二点五秒，为首领走位留空间 |
| 四分钟之后 | 完成双终端且击败巨兽后，在南侧撤离区连续停留四秒 |

每座终端半径二点六米，累计修复十二秒。可见的存活敌人进入圈内时暂停修复；离圈、暂停或升级都不会抹掉已获得的进度。每座终端完成后补充三十六发备弹、恢复十五点生命；装不下的弹药保留在地面。

敌人同时在场上限二十四，巨兽生命一千六百五十。设计重点是短时间驻留与主动退让，避免把修复写成必须站桩挨打的连续计时。

## 第三关：灰烬补给线

暖色车队遗址，南侧进入、北侧撤离。中央装甲车把街面分成两条可通行路线；三处物资依次散布在南段残骸、中央车队和北段残骸附近。回收顺序自由，可以留下医疗点供受伤后使用。

| 时段 | 压力与目标 |
| --- | --- |
| 开局至一分四十秒 | 步枪兵比例提高，间隔二点三秒；回收第一批物资 |
| 一分四十秒至三分三十秒 | 加入喷射者，间隔一点八秒；用侧路切断交叉火力 |
| 三分三十秒之后 | 巨兽出现，间隔二点四秒；扑击兽与喷射者配合 |
| 五分钟之后 | 全部物资回收且击败巨兽后，在北侧撤离区连续停留四秒 |

每处物资半径两米，累计回收三秒，不受圈内敌人争夺影响。每处补充七十二发弹药、恢复三十点生命、补回一枚手雷；生命和手雷分别受生命上限、三枚上限约束。每个点只结算一次。

敌人同时在场上限二十八，巨兽生命一千八百一十五。设计重点是穿越火线与资源取舍，区别于上一关的清圈修复。

## 第四关：最后封锁

紫灰色隔离区，南侧进入、北侧撤离。错位路障引导玩家按南、西、北的路线关闭三个封锁节点，西侧车辆提供绕行路线。所有节点可在地图上预见，但只有当前节点可以操作。

| 时段 | 压力与目标 |
| --- | --- |
| 开局至两分钟 | 突击兵、步枪兵、扑击兽混编，间隔二点二秒 |
| 两分钟至四分钟 | 加入喷射者，间隔一点八秒；完成节点并保留补给 |
| 四分钟之后 | 全部节点关闭后才能生成巨兽；常规间隔二点四秒 |
| 六分钟之后 | 完成所有节点并击败巨兽后，在北侧撤离区连续停留五秒 |

每个节点半径二点六米，累计操作十秒，争夺和奖励规则与通信终端相同。提前完成节点不会提前释放巨兽；超过四分钟才完成节点，会在随后模拟帧尝试生成首领。

敌人同时在场上限三十，巨兽生命二千零六十二点五。设计重点是顺序推进及组合敌人；不通过突然中断或强制扣血制造失败。

## 共通规则

- 三阶段节奏、敌人组合、地点和任务时间由同一份关卡配置驱动。
- 非首领随时间增长的生命在三分钟处封顶，避免延长关卡导致无限数值膨胀。
- 首领生成前预留一个敌人名额；生成位置必须容纳对应体型、与其他敌人保持间距且可达。
- 计时结束后停止生成常规敌人，但继续每四十五秒补给，允许缺弹玩家完成剩余目标与首领战。
- 撤离必须同时满足时间、全部目标、首领已击败，以及连续停留要求。离开撤离圈重置撤离计时；死亡优先于胜利结算。
- 战役选关、重试、下一关重新初始化局内状态，保留选择的武器、配件及角色外观。最后一关结算不显示不存在的下一关。
- 进度只在正常入口通关时保存；验收入口不写成绩或解锁。存储拒绝时当前会话仍可继续，界面明确提示。

## 验收基准

目标点、撤离点对玩家、中型敌人及首领体型的可达率必须为百分之百；错误通关、重复奖励、隔墙交互、地图间碰撞串用、负弹药的允许数量均为零。界面在桌面及窄宽度下不横向溢出，图标采用正常文档流布局。

自动化样本覆盖任务争夺、暂停、顺序、奖励、死亡与撤离门禁、存储失败，以及资源回收。额外固定基准对三关与三种标准武器的九种组合跑完整流程，使用正常生命、正常伤害和有限弹药，检查通关、弹药守恒及人数上限。随机种子固定为四十二，导航及升级选择由可复现脚本完成。

这些样本证明流程可完成，不证明所有玩家、所有种子或所有硬件上的平衡与性能。真人多轮难度、实机触屏和长期性能仍需单独验收；本次不声称达到生产力工具的人工节省百分之八十指标。
