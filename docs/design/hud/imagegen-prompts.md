# 《静默回声》战斗界面设计记录

使用内置 ImageGen，共生成战斗 HUD、暂停菜单两张设计图。输入为现有游戏的真实截图；生成图用于视觉规格，不作为覆盖游戏的静态图片。实际场景继续由三维引擎渲染，生命、弹药、任务、地图和字幕读取战役状态。

## 战斗 HUD 提示词

用途：游戏界面设计图 ui-mockup。为《静默回声》重新设计实际游玩 HUD。参考图是当前游戏截图：保留截图的所有三维场景、地面、楼梯、人物位置、俯视角、光照和画面比例，场景不要美化、不要另造场景；只重做覆盖其上的 HUD。目标是成熟商业单机战术生存游戏、克制、轻薄、有游戏感，主要游玩视野保持空旷。界面不要大方块、卡片、长说明段落、人物全名和重复标签。色彩为柔白、低饱和灰与少量暖琥珀金，阴影保证可读性。左上约30px边距：很小的章节位置“01 · 静默入口 / 地下维修层”；其下只一行当前目标“进入地下维修层”，前有细小琥珀目标图标，右侧“11 m”。右上三个小图标按钮：档案、空袭、暂停，显示很小的 J / C / Esc 快捷键；无大边框、无按钮文字块。左下：直径约90px的圆形低透明小地图，下面一条约150px宽、3px高生命条和小十字、数字100。右下：白色大号弹匣数字24，小号 /120，旁边小枪械轮廓；下面是手雷小图标、3、小型空格键提示。没有队友时不画空队友卡片。底部中央仅一行轻量无线电字幕“海斯？皮尔斯？听到请回答。……这里是里德，我还活着。”上方小字“梅森”，无大矩形底板、不要无线电静默字样。不要游戏标题、不要网页边框、不要品牌标志、不要时间倒计时。所有文字都应是游戏内 HUD 的尺寸，不能像网页标题那样巨大。输出一张完整、可直接照着实现的高保真游戏 HUD 设计图，横版16:9。

产物：`hud-reference-v1.png`，1672×941。图中地图实际较提示词更大，实现采用图上的比例，并为窄窗口缩小。

## 暂停菜单提示词

用途：ui-mockup，为《静默回声》配套设计暂停菜单。参考图是实际游戏画面，保持原场景、人物、俯视角、地面楼梯不变，画面只整体压暗并轻微虚化；去除参考图所有旧 HUD。不要换成电影插画，不要改善场景资产。设计成熟单机战术游戏的暂停叠层：左侧约9%处，垂直居中偏上。最上方很小的灰色“01 · 静默入口 / 地下维修层”，下面中等大但克制的白色标题“已暂停”。再下方一行小灰字“进入地下维修层”。四个纵向菜单项：“继续行动”“重试检查点”“装备整备”“返回主菜单”。当前选中“继续行动”用柔和琥珀字色和短细金色竖线标记，菜单行没有大色块、方框或卡片。底部左侧只一条小字“Esc 返回游戏”。其余约70%画面不放UI。无键位说明段落、无长提示、无游戏介绍。字体与HUD一致，灰白和琥珀金色，简洁、安静、孤独，横版16:9、高保真、可直接实现的暂停游戏画面。

产物：`pause-reference-v1.png`，1672×941。

## 实现资产

复用项目已有图标、枪械轮廓和地图数据绘制，没有增加贴满画面的图像层。所有图标按钮留在弹性或网格布局中，字幕、交互和短提示按实际状态显示。
