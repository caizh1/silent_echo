# 开始界面视觉与功能验收

final result: passed

VERDICT: PASS

## 范围与基线

本轮处理开始界面，不扩展战役内容。原界面同时显示首页、任务、无线电和生命弹药栏；原因是初始入口未设置菜单状态，战斗 HUD 的层级高于菜单。修复同时覆盖初始标记和每次模式切换，不依赖视觉遮盖。

设计依据为内置 ImageGen 生成的 `docs/design/menu/start-screen-reference-v1.png`。纯背景资产为 `public/images/menu/start-background-v1.png`。实际交付截图为 `docs/design/menu/start-screen-implemented-v1.jpg`，对照图为 `docs/design/menu/start-screen-comparison-v1.jpg`。两张图已在同一个并排输入中检查，并补看标题和菜单局部。

## 对照与迭代

1. 采用雨夜港城、独行士兵、左侧标题和五项纵向导航，移除首页剧情段落、章节清单、战斗状态和快捷键大全。
2. 对照生成图校准标题、英文副标题、菜单起点、行距和底部留白。取消正常存档状态说明，只在加载或存储异常时提示。
3. 修正资源就绪后默认选项：有检查点时继续，无检查点时开始新游戏。鼠标选中与键盘焦点同步。
4. 用真实按钮叠加纯背景，检查持续可交互性；加入独立章节、设置、操作说明和重开确认页面。
5. 最终对照：参考图等比例缩至 1366×769，实际截图为同尺寸、像素比 1。标题位置、五项顺序、琥珀选中条、主色和人物构图一致。原图文字为图像字形，网页使用系统中文字体，保留可编辑性和清晰度。

## 排版及交互

- 标题、菜单、返回按钮、状态和图标均用弹性或网格布局，没有使用绝对定位布置图标。
- 1366×768、1366×769、820×900、640×480 完整截图检查通过，未见菜单互相遮挡或超出可点击区域。
- 1920×1080 和 820×1180 的 DOM 几何检查通过：五项菜单均在视口内，首页没有战斗 HUD。内置浏览器在超过本机绘制区域时会裁切截图，未将这些裁切结果当作完整视觉证据。
- 背景保留比例，窄窗口调整裁切和暗度，使人物与标题仍然可读。
- 鼠标、方向键、回车、返回键经过实测；禁用的继续选项不会成为键盘选中项。
- 章节选择保留 16 章及原解锁限制。武器配置和三维预览继续可用。
- 新游戏、暂停、回到首页、继续、取消重开和刷新读档经过实测；菜单态和游戏态互斥显示。
- 声音开关在加载前设置静音时也会应用到新建音频主音量；静音时暂停共享音频上下文，枪声和换弹声不能绕过设置。
