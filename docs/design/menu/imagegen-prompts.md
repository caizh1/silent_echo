# 《静默回声》开始界面图像来源

## 生成方式

使用内置 ImageGen 生成，未使用外部计费模型或 Tripo。先生成完整菜单概念图，再通过同一工具移除文字和按钮，得到实现用的纯背景。浏览器中的标题和五个选项均为真实文字、真实按钮。

## 第一轮：概念图设计要求摘要

以用户提供的旧界面截图作为反例，重新设计横向 16:9、约 1920×1080 的电影式游戏主菜单。雨夜、黎明前的空港城，右侧为背对镜头的独行特种兵，湿地面反光、远处工业设施与雾气。冷青灰和炭黑为主，远处少量暖琥珀灯光。左侧留出暗色区域，上方为「静默回声」与「SILENT ECHO」，下方纵向仅保留「继续游戏、开始新游戏、章节选择、装备整备、设置」，选中项使用细琥珀竖线。底部只保留上下选择与回车确认的简短提示。去除战斗状态、说明段落、任务列表和浏览器边框。

概念图：`start-screen-reference-v1.png`，实际尺寸 1672×941。

## 第二轮：背景编辑提示词

编辑这张游戏主菜单概念图，产出实现用的纯背景图。严格保持原图的横向16:9画幅、镜头、雨夜港城场景、右侧背对观众的特种兵、建筑、远方烟雾、湿地反光、冷青灰色调、远处少量暖琥珀灯光及原有明暗构图。只删除左边所有文字：静默回声、SILENT ECHO、全部五个菜单项、底部按键说明；同时删除菜单选中条、金色竖线及任何UI。自然补全原文字背后的纯场景，左侧仍保持非常暗且安静的留白。不要加入任何新的字母、文字、标识、水印或界面。生成高质量、清晰的电影级游戏主菜单背景。

输入：`start-screen-reference-v1.png`。

实现资产：`public/images/menu/start-background-v1.png`，实际尺寸 1672×941。

## 实现约定

- 使用正常文档流的弹性布局承载标题、菜单与底部提示。
- 有存档时优先选中继续；无存档时继续置灰，选中开始新游戏。
- 章节、装备、设置独立显示；游戏进行时隐藏整幅开始页背景。
- 窄窗口调整背景裁切与暗度，保留可读文字和人物主体。
- 不将任何不可点击的文字或按钮烘焙进实际背景。
