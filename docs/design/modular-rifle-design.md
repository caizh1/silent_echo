# 自动步枪模块化重装方案

## 当前状态

用户要求自动步枪增加配件，在视觉上更加厚重，并希望配件以后可以独立建模和安装。本文件记录游戏美术与资产组织方案，不涉及现实枪械结构或装配。

现有第一版图片保持不变。第二版图片修改请求尝试两次，均被图片生成服务的安全系统以暴力类别拦截，第一次发生在输入阶段，第二次发生在输出阶段。没有生成可交付的新图片，不能将本方案记为已出图或已批准。

## 外观方向

保留原步枪主体辨识度、护木轮廓及石墨灰和暗橄榄配色。通过上方瞄具、前下方握把、侧面灯具、较厚弹匣和较厚枪托增加体量。琥珀色装饰光保持克制，不用大量细碎附件堆叠制造复杂度。

| 独立外观件 | 视觉目标 | 游戏资产替换规则 |
| --- | --- | --- |
| 瞄具 | 外形更饱满、顶部轮廓更明显 | 替换原瞄具，顶部槽位只显示一个版本。 |
| 前握把 | 短而厚实，增强前下方轮廓 | 使用独立前部挂点，可装备或卸下。 |
| 灯具 | 紧凑的侧面模块 | 使用侧面挂点，避免遮挡握持空间。 |
| 弹匣 | 体量更厚，长度不过分增加 | 替换原弹匣，不与原弹匣重叠。 |
| 枪托 | 增加贴腮区域与肩垫的视觉厚度 | 替换原枪托，保留步枪总体比例。 |

## 未来建模方式

步枪主体、五类配件分别作为独立模型。原版中可更换部件也需要从主体中分离，不能把完整原枪和新配件直接叠放。主体仅保留不可更换的外观与游戏资产挂点。

各模型统一坐标轴、缩放与连接基准，在建模软件中校准挂点偏移后导出。运行时根据槽位选中一个部件版本，以挂点变换放置，不依赖人工逐帧调整。展示图里分开摆放的配件，不等于已经校准可直接组装的模型。

配件初期只保证适配这支步枪；未来其他枪械复用时需要独立声明兼容性并验证。动画需分别检查握把与手部接触、弹匣换装路径、瞄具遮挡和枪托贴肩。仅增加外观不自动改变游戏数值，属性效果在设计确认后另行明确。
