# 移动时人枪分离修复

## 复现与根因

用户在正常游戏中发现身体移动后离开枪械。用当前真实士兵、骨架、权重和行走片段构造回归样本，修复前身体相对角色根节点漂移最大为 2.773 米。

行走片段的主要平移位于 Hip，而非 Root：Hip 的局部平面位移跨度约一点四四五米，归一化后造成身体偏离。旧代码只清除 Root 的部分坐标，实际行走位移仍会随动画播放。武器和模拟角色继续位于共同父节点，因此画面中身体走离了枪，也偏离实际碰撞位置。

同时复现了停止移动后的腰部旋转累积，固定瞄准重复更新后误差约 2.319 弧度。动画混合器可能跳过未变化的属性写入，手工姿态不能假定下一帧必定被动画重置。另发现左手原握点超出部分姿态的可达范围，最大误差约二十二厘米。

## 修复

- 在人物模型外增加独立步态层，每次采样动画后按 Hip 在父坐标内的位置抵消水平位移，保留垂直起伏。人物与枪仍共用模拟角色根节点。
- 手动瞄准和双臂约束前恢复上一帧保存的原动画姿态，再采样当前动画，避免腰部和手臂旋转重复累积。
- 在枪体上设置真实握点对象，双手约束读取握点世界坐标；调整枪的横向位置和左手支撑位置，保证行走、全向瞄准和换弹时可达。
- 分离资源加载与姿态组装，用真实骨架和网格进行自动检查；姿态诊断值通过页面数据属性提供给浏览器只读核对。

原始模型、母版、索敌和伤害参数没有修改。

## 验证

二十四项检查及生产构建通过。新增四项覆盖真实行走循环、停止后的连续瞄准、八方向移动配合八方向瞄准与换弹、实际蒙皮顶点和枪体的同步平移。

移动和瞄准组合共检查 5760 帧。最大身体水平误差按六位小数为零米，右手握点误差按六位小数为零米，左手最大 0.008851 米；均满足身体小于一毫米、握点小于三厘米的门槛。

Chrome 实际连续按下右移、下移、反向和上移后，身体与武器同步改变世界坐标，正常射击、击倒、换弹与升级仍运行，未观察到浏览器错误。近景图为 actor-attachment-verified.jpg。内置浏览器已重新加载当前修复版，另确认正常射击与姿态诊断生效；持续按住移动的浏览器验收使用 Chrome，内置浏览器的快速按键自动化不作为持续移动证明。

## 审查

VERDICT: PASS

P0/P1 BLOCKERS：无。已反证核对模型层抵消的是父坐标内的平移，没有清除模拟移动；实际蒙皮顶点和枪都通过等量平移检查。仅恢复被手动修改的五根骨骼姿态，保留其余骨骼动画。手部目标由枪体世界坐标给出，方向变化与换弹共用同一套挂点。原有战斗、暂停和结算测试仍通过。

UNVERIFIED RISKS：没有将本次修复等同于完整手指抓握、扳机动作或所有近距离穿插的最终美术验收，也没有重新完成三十分钟稳定性检查。

NON-BLOCKING FINDINGS：当前握点与双臂仍使用程序约束，后续可用专门的持枪动画精修手指和肩部姿势。
