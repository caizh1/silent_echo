# 战斗核心交付记录

## 范围与授权

用户已明确回复“好的，按建议路径开始”，授权正式进入代码开发。本次落实推荐路线中的第一阶段：真实模型接入、移动、相机、自动射击、训练目标、碰撞、受击与重试闭环，同时加入战中强化和训练成绩保存。

三分钟演练是战斗核心的验证载体，不替代原计划的八至十二分钟正式关卡。训练目标与建筑体块在入口和游戏底栏明确标记为非最终美术，不改变其他资产的审批状态。

## 实现

- Vite、TypeScript、Three.js 和 WebGL2，本机 Chrome 运行。
- 固定每秒六十步模拟，渲染与模拟分离，暂停和后台切换停止推进模拟。
- WASD、方向键控制平面移动，对角线速度归一化，移动按小步分解以防穿墙。
- 玩家保持画面中央，滚轮缩放；遮挡角色的建筑透明。
- 保留实际行走动画，去除动画根节点的平面位移；上半身朝向独立于腿部方向，通过两段骨骼约束靠近步枪握点。
- 自动选择射程内、存活且未被掩体遮挡的最近目标。二十四发弹匣，自动换弹，无限备用弹药。
- 双方弹道使用线段连续碰撞，按最近碰撞点判定，墙体优先阻挡后方目标。
- 训练追击者近战，训练射手发射可躲避的慢速弹丸。网格距离场引导绕过障碍，限制同屏训练目标数量。
- 击倒掉落经验，接近自动吸附；升级暂停并提供伤害、射速、生存三种强化。
- 死亡或三分钟结束后结算；重试重置状态。IndexedDB 以独立局次标识存储训练记录，重复写入不会产生重复记录。

## 验证

十一项自动测试通过：等速移动、移动穿墙防护、连续碰撞几何、无视死敌与墙后敌人、最近目标命中、双方掩体阻挡、自动换弹、暂停冻结、升级防重复选择、终局状态冻结、三分钟完整状态机基准。

三分钟自动基准增加了玩家生命值，只用于验证状态机、碰撞和数量上限，不作为正常难度可通关或游戏平衡证据。

Chrome 实测已确认真实模型载入、方向键移动、墙体阻挡、自动射击击倒、受击、经验吸附、三选一升级、升级后生命与上限变化、暂停与恢复。另已在真实 Chrome 中观察四十八秒演练结束、二十八次击倒的失败结算及本机记录保存成功。重试后界面恢复三分钟、生命一百、弹药二十四、击倒零，已在 Chrome 回读确认。暂停前后模拟时间均为五点九八秒，证明暂停期间未推进。实际画面在约一千零七十五乘六百五十八的浏览器视口下显示约一百二十帧，取样时目标数量约八个；不代表最终一千零八十高清、六十敌人压力场景通过。

## 高位横向镜头调整

根据用户反馈，镜头改为从正 X 轴方向俯视，俯角约六十二度，街道横贯画面。默认镜头高度二十四米，水平偏移十三米；滚轮缩放仍保持同一角度。输入同步改为屏幕坐标：右移对应负 Z，上移对应负 X。Chrome 中分别按右和上进行实测，位置从初始零、五变为负二点二、二点八，方向映射正确。构建通过。
