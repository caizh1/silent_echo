# 敌人倒地动画

## 目标与实现

原表现是敌人生命归零后立即消失。现在五类敌人都会保留死亡前的朝向、步态和持枪姿态，通过十一处骨骼控制骨盆、脊柱、颈部、肩肘和髋膝，依次完成受击失衡、屈膝卸力、躯干倒地和肢体停稳。

人类倒地约需 1.25 秒，普通外星敌人约需 1.45 秒，首领约需 1.7 秒。倒地方向参考致命子弹或爆炸方向，并按敌人编号加入少量侧转。人类和外星敌人采用不同的前肢松弛幅度，外星敌人下垂的腹甲保留在躯干权重中。手持武器单独脱手、旋落并贴地。

死亡当帧结算击杀和掉落，并从存活列表中移除；尸体不攻击、不被锁定、不占敌人生成名额。尸体最多保留九秒，最后一点五秒以抖动方式淡出，同时淡出阴影。场景最多保留六十四具尸体，落地后的骨骼不再重复计算。

暂停和强化选择期间冻结倒地。胜负结算后允许表现时钟继续，以确保最后一击的倒地动作播完。重新部署或换图时释放独立的几何、材质、骨架及脱手武器。

相关文件：`src/enemy-motion.ts`、`src/enemy-death.ts`、`src/models.ts`、`src/simulation.ts`、`src/main.ts`。

## 验证记录

- `npm test`：八十八项测试通过，其中十一项覆盖新增死亡流程。
- `npm run build`：类型检查与生产构建通过；仍有现有主包体积提示。
- 使用五个真实敌人网格检查存活姿态交接、独立关节弯曲、地面最低点及落地稳定性。
- 检查子弹与手雷致命方向、奖励只结算一次、暂停冻结、数量上限、终局继续倒地，以及重开和到期资源释放。
- 后台无头浏览器加载实际游戏：五类敌人同时死亡、暂停、重新部署、六十个人类敌人同时死亡和到期回收通过。无脚本或着色器错误。
- 六十具尸体样本的六十帧观测平均耗时约 16.31 毫秒，最大约 24.70 毫秒。这是当前后台浏览器的短样本，不能代表所有设备或长时间性能。

- 五类落地画面：`outputs/enemy-death/all-enemies-settled.png`。
- 实际游戏倒地画面：`outputs/enemy-death/game-collapse.png`。

## 审查

VERDICT: PASS

P0/P1 BLOCKERS:

无。检查了死亡结算与攻击顺序、子弹和爆炸方向、暂停及终局时钟、重开时编号复用、资源释放、阴影淡出和尸体数量上限；未发现成立的严重阻塞问题。

UNVERIFIED RISKS:

移动设备及长时间连续战斗的实际性能未验证。自然程度仍包含主观视觉判断，需要在实际游玩中确认。

NON-BLOCKING FINDINGS:

这是程序化分关节动画与平地接触拟合；没有加入完整刚体布娃娃、尸体之间或尸体与车辆和建筑的碰撞求解。贴近障碍物时，部分肢体仍可能与障碍物相交。原静态网格采用空间权重，复杂外星体型的形变精度低于人工逐顶点蒙皮。
