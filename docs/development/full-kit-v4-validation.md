# 原图完整武装适配与游戏验收

## 实现结果

按用户确认的正背目标图，先校准完整母版，再拆分可穿戴部件。游戏新增“全副武装”预设，在第三版素装士兵骨架上穿戴完整装备，保留已通过方向检查的新头脸。全装没有切回旧角色；“原主角”仍是独立对照项。

原图中的八个主要区域均有对应几何和实际显示。该覆盖结果不等同于美术相似度评分，也不宣称已复刻原画全部织物、磨损与灯光细节。

| 原图区域 | 当前实现 |
| --- | --- |
| 头部 | 头盔、耳机、独立目镜；透明镜片保留可见眼睛 |
| 胸背 | 原始母版提取的三联弹匣袋胸甲、两侧护甲及贴背背包 |
| 肩颈 | 可独立拆卸的双肩甲、臂带和作战护领 |

共十五类穿戴位置，包含十四类开关与一类三档互斥防弹衣；全套由四十一组装备节点构成。三档防弹衣是替换关系，第三档由胸前和左右侧甲共同组成。素装、轻装、中装、全装和旧角色均可切换。

## 建模与绑定

- 从原始全装士兵的实际静止形体提取胸甲、背包、腰带、腿包与护具，保留贴图。排除骨骼辅助对象，避免辅助球体参与身高计算。
- 按关节位移场适配新人体跨度，避免把两次自动绑定的骨骼滚转差异施加给护具；护膝始终朝前，腿包保留左右侧方位置。
- 腿部和腕部固定带根据新基础人体表面重新建模，带扣使用真实倒角几何。胸甲下腹和背包两侧始终保留完整衣服，单件卸装不会露出贯穿身体的空洞。
- 硬质腿包、膝甲和胫部护具采用对应腿骨约束，软质部件保留归一化蒙皮权重。新旧角色与预览各自使用独立骨架。
- 清除仅用于提取的旧人物、辅助对象及旧动作，运行副本只有四十一根骨骼和一段一百二十三轨道的行走动画。
- 新增正确处理非骨骼父节点缩放的静止姿态恢复，展示与战斗姿态切换不会把身高放大或让头部被裁切。

运行文件 public/models/game/modular-soldier-v4.glb 为 16,978,700 字节。包含全部互斥件时为 141,362 三角面；全装展示实际绘制约 122,146 面。贴图全部内嵌，生产构建中的模型与运行源文件逐字节一致。

可编辑母版为 assets/models/masters/modular-soldier-full-kit-v4.blend；加工脚本为 scripts/prepare-full-kit-v4.py；渲染脚本为 scripts/render-full-kit-v4.py。第三版、原角色、独立装备母版与原始 GLB 均保留。

## 实际验收

六十二项自动检查和生产构建通过。新增检查直接读取最终第四版 GLB：

- 十五类实际装备、全部归一化权重、护甲互斥及下腹服装完整性通过。
- 三种武器、标准和升级配件、行走、八方向瞄准与换弹共二千八百八十帧；头部局部漂移按六位小数为零，右握点误差小于一毫米，左握点最大约二点九四厘米。
- 护膝位于腿前；实际蒙皮顶点随角色等量平移。
- 装备展示基础人体高度约一米八一六；展示与动作反复切换后无累积变形或握点失联。
- 透明镜片为真实透明材质，所有图片内嵌；仅保留一段正确行走动作。
- 原有穿戴记录兼容，缺少新增字段时不擅自装备新部件。

Chrome 已操作全部十四类开关，逐类关闭后对应节点全部隐藏；三档护甲和素装、中装、全装及正背展示完成目视检查。全装行走、换弹以及三百二十和三百九十像素窄屏操作通过，最下方靴子按钮可点击且无横向越界。E、Esc 和双向 Tab 焦点循环通过。

独立交付另含十九个 GLB：一个素装、一个完整全装和十七套装备分件。每个文件独立导入通过，均保留四十一骨骼与蒙皮；素装静止身高为一米八二，全装与对应分件的世界边界最大差异为零米。独立全装只包含第三档胸甲，直接打开也不会叠穿三档。分件与完整模型共享绑定坐标，详细清单见 docs/modeling/full-kit-parts-v4.json。

换装菜单的滚轮不会再误改战场镜头；长装备列表可正常滚动。预览关闭释放独立图形上下文及骨骼纹理，不释放共享材质、几何和实战骨架。

性能采样与浏览器操作明细见 full-kit-browser-v4.json。压力样本提高生命并关闭角色对敌伤害，维持六十敌人，不作为正常难度或长期平衡证据。

最终全装压力样本使用一千九百二十乘一千零八十渲染缓冲，预热后采样约五百八十九秒，平均约一百二十帧，百分之九十五帧间隔约十毫秒，约一百一十五次绘制。样本在角色验收生命耗尽后结束，结果不保存训练成绩。结束图为 outputs/full-kit-v4/game-stress-result.png。
