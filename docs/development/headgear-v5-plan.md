# 头部装备修正范围

用户要求保留现有脸型，修正头盔、目镜、耳机和下颌固定带，使全装头部更接近原始正背设计。

人工基线：第四版分别缩放三件独立生成装备；头盔破碎起伏，目镜镜框不连续，耳罩偏低，缺少清楚贴合的下颌固定关系。目标用户为游戏角色资产编辑者与玩家；输入为第四版可编辑母版、运行模型和原始设计图。

本次直接修改可编辑三维装备，不重新生成脸部，不消耗新的建模积分。第五版另存，第四版保留。支持现有四十一骨骼、十五类换装、装备展示、持枪、行走和换弹。面部、身体、既有非头部装备、动画和绑定坐标保持一致。

验收采用真实母版、实际导出模型和游戏后台浏览器：

- 比较基础人体顶点、拓扑、贴图坐标、权重与材质，确认脸部和人体没有被修改。
- 同灯光、同尺寸的正面、侧面、斜面近景比较连续盔壳、厚镜框、独立烟灰镜片、耳罩与下颌带。
- 检查三件可独立拆装，头部装备全部绑定头骨，动作与重复切换不漂移。
- 构建、实际模型动作检查和后台游戏截图验证实际加载第五版。

视觉还原采用人工逐项判断，不能用功能测试数、装备覆盖率或三角面数代替相似度，也不宣称达到减少百分之八十人工的生产力指标。原图细微磨损、摄影灯光与当前脸型的差异不属于本次几何修正范围。
