# 本地游戏端口隔离修复

## 现象与证据

用户从聊天链接打开 127.0.0.1:5173 后，在内置浏览器看到《弯道俱乐部》。现场盘点确认：同一地址在 Chrome 标签页标题为《破城前线》，内置浏览器标签页标题为《弯道俱乐部》；终端读取该端口实际返回《破城前线》的页面。两种浏览器环境出现分歧，旧来源曾由赛车项目使用，存在离线页面或缓存影响的可能。本轮未清理赛车缓存、注册项或存档。

## 修复

射击游戏开发地址固定为 http://127.0.0.1:5186/ ，生产预览端口固定为 5187。两者均启用严格端口检查，端口占用时直接报错，不自动递增。旧 5173 监听进程已核对为本射击项目的 Vite 服务，并在新服务就绪后关闭。

已将用户当前内置浏览器页面和 Chrome 中的射击游戏页面导航到新地址。内置浏览器回读标题为《破城前线 · 废城实战》，资源全部就绪，开始演练按钮可用。验证截图为 port-isolation-verified.jpg。生产构建通过。

## 审查

VERDICT: PASS

P0/P1 BLOCKERS：无。配置只影响本项目开发和预览监听，未修改战斗逻辑、赛车源码、缓存或存档。已核对新端口实际响应与用户浏览器页面。

UNVERIFIED RISKS：没有直接读取旧浏览器离线控制器，因此不将某一种缓存机制认定为已确认的唯一根因。

NON-BLOCKING FINDINGS：历史聊天中的旧链接不会自动改变，之后统一使用新地址。
