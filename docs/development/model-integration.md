# 城市、车辆与敌人模型接入

## 本轮范围

用户要求将此前生成的全部模型接入游戏。本轮覆盖士兵与步枪之外的十类静态资产：商店废墟、道路掩体、轿车残骸、装甲车残骸、警车残骸、人类步枪兵、人类突击兵、外星扑击兽、外星喷射者、外星首领。不会将生成设计图但尚未建模的其他主武器或配件说成已接入。

## 目标与边界

目标用户为本机 Chrome 玩家，只使用方向键或 WASD；输入为已下载并保留母版的真实 Tripo 模型。验收样本为十类资产和原士兵、步枪样件，要求资源全部加载、各类实际进入场景或战斗、物件阻挡与弹道一致、暂停和重试正常。

人工基线为逐个导入、处理比例朝向、减面、逐张贴图校验、摆放物件和手动复核。本轮使用确定性导出脚本与固定自动基准减轻重复检查，没有将此游戏资产工作宣称为已量化降低百分之八十人工。资产加载必须全部成功才允许开始；任何一类失败不以训练体块替代。

游戏仍为三分钟战斗场景，未实现完整八至十二分钟正式关卡、局外经济、全部主武器和永久升级。新增敌人使用原始外观的合批渲染和程序步态、瞄准姿势，不代表最终骨骼、持枪和换弹动画已通过。

## 实现

- 原始 GLB 和 Blender 母版保持不变；另行导出游戏副本，七千至两万三角面，三张一千像素贴图。
- 玩家继续使用原有骨骼动画和实际自动步枪。敌方持枪模型取自同一把已生成步枪，减少到两千八百面并把材质采样成顶点色，减少绘制次数。
- 四座废墟、四块道路掩体、三辆残骸车的摆放与碰撞由同一份配置生成；尺寸来自导出的实际模型。建筑被相机遮挡时透明化。
- 三辆车使用独立动态火焰、烟雾和火光，不把特效固化到模型里。暂停、升级和结束时随模拟时间冻结。
- 人类突击兵近战，步枪兵蓄力射击，扑击兽预警后冲刺，喷射者三发散射，巨兽预警后范围攻击；预警位置锁定，可通过走位躲开。
- 距离场按三档体型计算，刷怪只允许落在玩家可达区域。首领两分钟出现一次，击败首领且撑到三分钟后结束。
- 五类敌人使用各自共享模型、材质与实例化绘制，连续重试复用资源；每帧只更新实例矩阵和状态，不反复分配敌人几何。

## 验收模式

开发服务支持五类敌人验收和六十敌人压力验收，两者均使用额外生命且不保存成绩。压力模式保持零玩家伤害，使六十个实际敌人持续存活；仍运行寻路、碰撞、蓄力、弹道和受击。此模式通过真实的 1920×1080 渲染缓冲进行压力检查，浏览器可见视口另行记录。

验收模式由开发环境门禁控制，生产构建不启用。它不证明正常生命值下的难度、通关率或长期平衡。

## 验证进度

自动检查首轮十九项通过。Chrome 已显示废墟、掩体、三辆燃烧车辆及五类真实敌人；五类验收场景中发生实际攻击、击倒与经验升级。浏览器检查时无着色器或资源错误。后续压力、暂停、重试与发布构建结果继续记录。

## 最终验证

二十项自动检查通过，类型检查和生产构建通过。新增覆盖了地图各侧的首领刷出与体型间距。原始模型校验值全部保持不变；十一份游戏文件合计 42,420,884 字节、125,796 三角面，包含一份从同一把步枪派生的敌方副本。十项静态资产的三张运行贴图均确认为 1024×1024。

本机硬件回读为 Apple M5 Pro、48GB 内存。Chrome、1920×1080 渲染缓冲、六十个真实敌人，预热后连续采样 65.82 秒，平均 120.05 FPS，百分之九十五帧间隔约 10.2ms；取样时约一百七十一次绘制、一百零五万三角面，无着色器或资源错误。可见视口为 1075×656，压力结果对应实际渲染缓冲的工作量。

暂停前后回读模拟时间均为 71.55 秒。重新开始后恢复三分钟、等级一、击倒零、六十敌人；额外生命属于验收模式，未保存成绩。生产构建即使带验收查询参数，仍显示正常开始按钮和一百生命，方向键移动通过。

在独立生产预览的构建副本上临时移走一个敌人模型，界面阻止开始并显示红色失败提示。发现并修复了其他资源的延迟进度回调覆盖失败提示的问题；失败状态现保持不变，资源恢复后重试可重新加载。故障注入未触及源码资产或母版。

三十分钟浏览器稳定性与正常生命值下的平衡没有在本轮完成。压力场景包含十二个巨兽以覆盖更高几何负载，不应把额外生命、零伤害或该敌人组合解释为正式玩法配置。
