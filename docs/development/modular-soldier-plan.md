# 模块化士兵与装备接入验收计划

## 授权与目标

用户明确要求重新生成素装士兵、完成三维建模，并将此前装备接入可穿戴角色。保留原士兵与原装备母版，另建游戏副本。总积分仍受原二千积分预算约束；本轮开始时项目余量九百四十积分，网站余额以实际回读为准。

## 人工基线与支持范围

当前游戏只加载固定旧士兵，十件新装备未接入；逐件手工导入、对齐、绑骨骼和反复切换验证。目标用户为本游戏玩家和资产制作者。输入是已交付的十件装备及新生成的素装人形角色。支持现有走路、八方向移动、瞄准和换弹；不声明支持游戏尚未实现的动作。换装本轮改变外观，不擅自新增装备伤害数值。

## 验收样本与指标

- 原主角作为可回退对照；素装、轻装、中装、重装至少四组新角色状态。
- 十件装备均有明确槽位和独立开关，三档防弹衣互斥，左右手脚与护膝成对处理。
- 用实际模型覆盖完整行走循环、转向、瞄准、换弹与暂停恢复，检查装备随骨骼运动、身体遮挡及姿态一致性。
- 默认游戏镜头和近景整备镜头均应可区分状态；窄屏操作控件不得遮挡或重叠。
- 记录模型覆盖数、面数、资源大小、加载耗时和浏览器帧时间；没有实测的数据标记为未验证。
- 所谓无缝以支持动作中无明显漂浮、重复装备和大面积穿插为目标，不能仅凭生成图或文件校验宣称通过。

## 质量边界

现有装备是独立生成初稿，部分有贴图污染和重建细节。先做样件适配，再扩展其余槽位。手套、靴子与软质护甲必须实际处理蒙皮或替换区域。不能将静态绑点等同于全部部件的动画变形通过。当前任务不属于模型自动审核等生产力功能，不声称已减少人工百分之八十。
