# 武器配件接入与验收方案

## 本轮目标与输入

面向本地桌面浏览器玩家，使用现成且授权清楚的免费外观模型，补齐初始手枪、冲锋枪、突击步枪的瞄具、弹匣、枪托、前握把以及有限数量的主动手雷。当前项目只有一把自动步枪，使用真实骨骼角色、独立弹匣和四十二项通过的回归检查。

人工基线是逐件查找来源与授权、下载、检查模型、转换格式、配置十一处武器配件兼容关系，再逐项检查动画、数值与碰撞。当前没有记录过同一批任务的完整人工耗时，因此不能宣称已经节省百分之八十人工。目标是让批量资源处理和固定回归承担至少百分之八十的重复检查；美术选型、贴合和正常难度平衡仍需目视与实机验收。

## 支持边界

- 使用游戏外观网格与游戏拟定尺度，不包含现实制造、内部结构或实物装配数据。
- 首选免费模型；账号限制、格式或风格不适配时使用明确允许商用的公开备选。保留原始来源与许可记录，禁止从三维预览中提取未开放下载的模型。
- 游戏运行模型使用内嵌材质的 GLB，统一朝向、比例和语义名称；原始文件独立保留。模型来源变化必须如实记录。
- 三种枪分别验证挂点。瞄具提升游戏命中率，弹匣增加单次装填量，枪托提升游戏射速，前握把同时改善游戏命中率与射速。
- 手雷按空格主动释放，数量有上限。暂停、升级、死亡和结算不接受投掷；移动不影响剩余数量；重开恢复初始数量。
- 用户已选择开局装备界面：默认手枪，开战前选择三种枪及兼容配件；开战后锁定配置，局内保留原有强化三选一。

## 质量指标与真实样本

- 对实际导出的全部模型验证可读取网格、有限顶点、有效材质、尺寸和文件路径；来源与许可覆盖率要求百分之百。
- 对三种枪的所有声明槽位验证兼容性、重复安装、替换、重开和换弹；要求零处严重穿插、脱手或枪口错位。
- 在真实角色和武器模型上运行八方向移动、八方向瞄准与换弹固定样本，身体漂移小于一厘米，双手误差不超过三厘米。
- 对弹药与手雷数量做守恒和边界检查；切换和加大弹匣不能凭空生成弹药，任意状态不能重复结算伤害或击杀。
- 对手雷检查近墙投掷、轨迹、爆炸范围、掩体遮挡、暂停和结算生命周期；严重漏判和错误伤害要求为零。
- 在本机浏览器完成正常游玩、配件安装前后、三种枪、空格投掷和窄窗口布局检查，并记录固定基准的耗时和通过率。现有正常难度平衡及百分之八十人工节省尚未验收。

## 审查方式

交付前对状态机、碰撞、弹药一致性、加载失败、资源生命周期和输入焦点进行开放范围审查。仅有具体可达路径及严重影响证据的问题才列为 P0/P1；未发现成立的 P0/P1 时给出 PASS，并单独说明未验证内容。
