# 燃烧警车建模记录

## 范围与授权

用户要求新增一辆着火警车，使用 ImageGen 出图后直接交给 Tripo 建模。本轮生成方式为内置 ImageGen，提示词见 ../design/burned-police-car-prompts.md。

设计图保存在 ../../assets/concepts/vehicles/burned-police-car-v1.png，显示燃烧效果和四方向视图。独立建模参考图保存在 ../../assets/models/tripo/inputs/burned-police-car/reference.png，已去除火焰、烟雾和橙色火光，保留同一警车残骸。设计板侧视警灯的颜色分布不如主视图清楚，建模统一以独立三分之四视角为准，不宣称四视图已通过几何一致性验收。

## 拟采用参数

高精度第三点一版、四万三角面上限、二千像素物理材质。当前页面单项报价四十五积分，提交前网站余额一千六百一十五积分，项目剩余预算一千四百三十五积分。

## 验收边界

目标为新增一份带贴图警车静态模型，核对警灯、黑白车漆、车体战损、文件完整性及本地双面渲染。火焰烟雾属于游戏动态特效，本轮不将其生成在静态网格中。生成、下载、本地检视和游戏接入分别记录。
