# 完整武装第四版

本包以用户正背原图为目标，提供完整装备母版、可拆装游戏模型、原图对照及真实模型渲染和游戏截图。

- 游戏副本：public/models/game/modular-soldier-v4.glb。
- 可编辑母版：assets/models/masters/modular-soldier-full-kit-v4.blend。
- 十五类穿戴位置、四十一组装备节点、四十一骨骼、一段真实行走动画。
- 采用新的素装头脸与原始全装造型提取部件；没有把全装切回旧角色。
- 游戏按 E 打开“角色换装”，点击“全副武装”查看完整效果；正面、背面、装备展示、行走和换弹均可切换。

运行副本包含全部互斥防弹衣，使用节点自定义属性区分槽位；第三档由胸前及两侧部件共同组成。编辑母版打开时为完整静止造型，其他档位保留在文件中。

六十二项检查与生产构建通过。当前完成完整轮廓与穿戴，织物磨损、手指抓握及最终近景细节仍有精修边界；尚未实现装备掉落、获取或属性成长。详细证据见 docs/development/full-kit-v4-validation.md。

本轮未新增 Tripo 消耗。原始十件独立装备与第三版模型仍保存在项目和既有交付包中，本包不重复收录。

独立 GLB 位于 assets/models/derived/full-kit-v4：base-soldier-v4.glb 是素装，full-kit-soldier-v4.glb 是可直接打开的完整第三档全装，其他十七个文件是各槽位与三档护甲的独立分件。十九个文件保留同一绑定坐标及四十一骨骼，独立导入与坐标一致性检查通过。静止文件不包含行走；有动画的合并运行副本另在 public/models/game 中。

母版与 GLB 可独立打开。重建和校验脚本依赖完整项目中的第三版母版、原始全装模型、现有装备及项目依赖；不在缺少输入文件的解压目录内单独运行。

编辑整套优先打开母版，其中全部部件已共用一副骨架。独立分件各带相同骨架便于移交；合并多个独立文件时，应复用同名骨骼并重指向公共骨架，避免保留多副重复骨架。游戏运行副本已经完成该合并。
