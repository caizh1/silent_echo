# 头部装备修正第五版

本次保留第四版脸型、基础人体、非头部装备及动作，重建连续硬壳头盔、连体密封战术目镜和通信耳机，补齐贴合下颌的固定带。已接入游戏，并导出同一骨架坐标下的独立分件。

查看 `comparison-front.png` 与 `comparison-side.png` 可比较同机位、同灯光下的实际游戏模型。`comparison-bare.png` 展示卸下三件头部装备后相同的脸部。`game-full-front.png`、`game-full-back.png`、`game-walk.png`、`game-reload.png` 为后台游戏实机截图。`after-front.png` 等为母版离线渲染。图片不可替代真实动作检查。

资源包包含第五版合并运行副本、可编辑母版、十九个独立模型、头部烘焙贴图、对照图、脚本和验收记录。合并运行副本保留三档互斥胸甲与一段行走；独立完整人物只包含最高档胸甲，不会同时叠穿三档。

独立部件使用同一四十一骨骼及绑定坐标；重新组合时复用同名骨骼。不要单独归一化每个装备的尺寸和中心。全部基础人体和非头部装备与第四版一致。

六十四项自动检查、构建、十九个独立模型的绑定坐标与实机拆装验证通过。具体证据和审查见 `docs/development/headgear-v5-validation.md`。本轮新增建模积分为零。

`compare.html` 是项目内交互对照页，通过本项目开发服务访问 `/outputs/headgear-v5/compare.html`，依赖项目的源码、旧模型及武器。处理脚本也依赖项目中的第四版母版；资源包并非独立重建工程。母版及模型本身可直接导入编辑器使用。

当前脸型与面部细节按要求保留；精细磨损和摄影质感仍有差异。未验证手机热负载或三十分钟稳定性，未改变掉落、解锁、属性与独立手指抓握系统。
