# 修正版素装士兵与穿戴装备

本包保留正确的第三版静态与行走角色、已适配的游戏 GLB、可编辑 Blender 母版、四视输入与验收图。错误第二版不包含在交付包中，仅在项目原始目录留档。

游戏运行文件为 public/models/game/modular-soldier-v3.glb，包含身体与十三个可切换装备网格，使用同一副四十一骨骼。可编辑母版为 assets/models/masters/modular-soldier-fitted-v3.blend。十件原始独立装备仍见上一批装备资源包，本包不重复收录。

游戏按 E 或点击“角色换装”比较素装与穿戴效果。首次使用默认素装，已有穿戴偏好继续保留；三档防弹衣互斥，其他七类可独立切换。当前装备只改变外观。

正背左右与鞋尖朝向已检查，五十八项自动检查及构建通过。手指没有独立骨骼，完整抓握与最终近景美术未完成；不要将本次接入等同于任意动作完全无穿插。详细证据见 docs/development/modular-soldier-validation.md。
